BACKEND SUMMARY (backend/)
- Projects: Core (models, interfaces, calculator, service), Infrastructure (Yahoo client+parser, caching decorator, DI), Api (minimal API), Tests.
- Endpoint: GET /api/stocks/{symbol}/daily-summary ; GET /health. Dev API: http://localhost:5241. OpenAPI JSON at /openapi/v1.json (Development only).
- Symbol regex (frontend must mirror): ^(?=.*[A-Za-z0-9])[A-Za-z0-9.\-^=]{1,15}$  (ASCII only; upper-cased by the backend).
- Data rules: days bucketed in the exchange timezone; averages in decimal rounded to 4 dp (away from zero); volume is a long sum. Oldest day first.
- Errors are RFC 7807 ProblemDetails, type urn:daily-stock-summary:problem:<slug>:
  invalid-symbol 400, symbol-not-found 404, rate-limited 429, upstream-unavailable 502, upstream-timeout 504, unexpected-error 500.
- Resilience: total timeout, retry (5xx/408/network/timeouts; never 404/429), circuit breaker, per-attempt timeout.
- Cache: 60 s TTL, single-flight per symbol, never caches failures or empty results, capped at 500 symbols.
- CORS: explicit origins from config (default http://localhost:5173), GET only. Rate limit: 60/min per client on the api policy.
- Symbol quirks: Yahoo spells Berkshire BRK-B (BRK.B gives not found). VOD.L, ^GSPC, EURUSD=X, BTC-USD work.
- Accepted gaps (in spec): shared fetch continues if all callers disconnect; cache expiry counts from fetch start; HEAD not routed.
- Phase 5 note: use forwarded headers behind a reverse proxy, tzdata in the container.
